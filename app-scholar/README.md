# APP Scholar - Sistema Acadêmico Integrado

##  Sobre o Projeto
O **APP Scholar** é uma plataforma acadêmica mobile focada na portabilidade operacional escolar técnica. O sistema gerencia os fluxos de dados de uma instituição de ensino de forma prática.

>  **Nota:** O projeto encontra-se atualmente em fase de desenvolvimento.

## Funcionalidades Mapeadas (32 Telas)
O aplicativo realiza o gerenciamento operacional (Cadastro, Consulta, Edição e Exclusão) de 10 eixos fundamentais:
- Alunos, Professores e Coordenadores
- Turmas, Cursos e Disciplinas
- Matrículas, Responsáveis, Avaliações e Boletins

##  Modelagem de Banco de Dados (MBDB)
Para suporte do sistema, foi modelado um banco de dados no **MySQL** contendo regras de integridade e a implementação de **10 Views relacionais** com múltiplos `JOINs` para geração de relatórios acadêmicos consolidados.

##  Tecnologias Utilizadas
- **Frontend Mobile:** React Native / JavaScript (Expo Snack)
- **Banco de Dados:** MySQL (phpMyAdmin)

## 📁 Estrutura da Pasta
- `App.js`: Código-fonte da aplicação React Native (Em desenvolvimento).
- `views_academicas.sql`: Script SQL contendo a criação das 10 Views do banco de dados.
